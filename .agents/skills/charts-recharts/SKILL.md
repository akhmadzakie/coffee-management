# Charts Recharts

## Aturan
- Pilih grafik sesuai pertanyaan: tren waktu (garis), perbandingan kategori (batang), komposisi sedikit kategori (batang bertumpuk; hindari pie dengan banyak irisan).
- Sumbu bernama dan berformat (Rp, jam); tooltip menampilkan angka lengkap.
- Warna dari token tema dan tidak menjadi satu-satunya pembeda (tambahkan label atau pola).
- Komponen grafik adalah Client Component; data diagregasi di server dan dikirim ringkas.
- Beri ringkasan teks atau tabel alternatif untuk aksesibilitas.
- Tangani data kosong dan satu titik data dengan tampilan yang masuk akal.
