# Git Commit Formatter

Format: `tipe(scope): ringkasan singkat`
Tipe: feat, fix, refactor, test, docs, chore.
Contoh: `feat(orders): tambah split bill`, `fix(inventory): cegah stok negatif`.
Satu commit satu perubahan logis. Jangan commit `.env` atau secret.
