---
description: Alur standar membuat fitur baru
---
1. Tanyakan tujuan fitur dan aturan bisnis yang belum jelas.
2. Cek skill yang relevan dan ringkas aturan yang berlaku.
3. Usulkan rencana singkat (file yang diubah, perubahan schema) dan tunggu persetujuan.
4. Implementasi: schema -> logika (fungsi murni) -> action -> UI.
5. Tulis test, lalu jalankan `npm run check`.
6. Rangkum perubahan dan buat commit message sesuai skill git-commit-formatter.
