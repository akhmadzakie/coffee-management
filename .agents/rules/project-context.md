# Konteks Proyek
Web app manajemen coffee shop: POS, order, stok bahan, shift, laporan.

## Stack
Next.js (App Router) + TypeScript + PostgreSQL + Prisma + Zod + Tailwind + shadcn/ui + Vitest.

## Aturan Umum
- Bahasa UI: Indonesia. Nama variabel dan kode: Inggris.
- Uang selalu Int (Rupiah). Dilarang Float untuk uang atau stok.
- Jangan menjalankan perintah destruktif (drop, reset database, rm -rf) tanpa konfirmasi saya.
- Jangan menambah dependency baru tanpa menyebut alasannya.
- Fitur yang menyentuh uang atau stok wajib disertai test.
- Gunakan skill yang relevan di .agent/skills sebelum menulis kode.
- Jika ragu soal aturan bisnis, tanyakan, jangan menebak.
